# speed net API — نسخه ابتدایی و آموزشی

این یه نسخه خیلی ساده از یه API مدیریت کاربره — قدم اول برای ساختن یه پنل مثل PasarGuard.

فعلاً فقط کاربر می‌سازه، لیست می‌کنه، فعال/غیرفعال می‌کنه و حذف می‌کنه.
**هنوز به Xray-core وصل نیست و کانفیگ واقعی v2ray نمی‌سازه** — این قدم بعدیه.

## چطور اجراش کنم؟

### ۱. نصب پایتون
مطمئن شو پایتون ۳.۱۰ به بالا نصب داری:
```bash
python3 --version
```

### ۲. ساخت محیط مجازی (پیشنهادی)
```bash
python3 -m venv venv
source venv/bin/activate      # روی ویندوز: venv\Scripts\activate
```

### ۳. نصب پکیج‌ها
```bash
pip install -r requirements.txt
```

### ۴. اجرای سرور
```bash
uvicorn main:app --reload
```

### ۵. تست کردن
مرورگر رو باز کن و برو به:
```
http://127.0.0.1:8000/docs
```

یه صفحه تعاملی (Swagger UI) می‌بینی که می‌تونی مستقیم از توش:
- کاربر جدید بسازی (`POST /users`)
- لیست کاربرها رو ببینی (`GET /users`)
- کاربر رو فعال/غیرفعال کنی (`PATCH /users/{username}/toggle`)
- کاربر رو حذف کنی (`DELETE /users/{username}`)

## ساختار پروژه
```
speednet-api/
├── main.py         # فایل اصلی، اندپوینت‌های API
├── models.py        # ساختار جدول‌های دیتابیس
├── schemas.py        # شکل داده‌های ورودی/خروجی
├── database.py        # تنظیمات اتصال به دیتابیس
└── requirements.txt      # لیست پکیج‌های لازم
```

## قدم بعدی چیه؟
وقتی این بخش رو فهمیدی و تست کردی، قدم بعدی اینه:
1. اضافه کردن احراز هویت (Authentication) برای ادمین
2. اتصال به Xray-core برای ساخت کانفیگ واقعی VLESS/VMess
3. ساخت لینک Subscription برای هر کاربر
4. اضافه کردن یه فرانت‌اند ساده که به این API وصل بشه

هر وقت آماده بودی بگو بریم سراغ قدم بعدی.
